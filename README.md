## Current Focus

I am exploring how AI agents can become more useful when they are given structured, domain-specific workflows instead of one-off prompts. My current work is about packaging repeatable tasks into reusable skill directories that are easy to read, install, fork, and improve.

Some themes I care about:

- Making research and paper-submission workflows easier to execute
- Turning messy operational tasks into clear checklists and scripts
- Building small AI tools that save real time or real money
- Creating open-source repositories that are understandable enough for others to reuse directly
